Desenvolvido na disciplina de **Desenvolvimento Web com React** da residência em software do **Serratec (2021)**.

Loja virtual de um petshop, do ponto de vista do cliente. A versão do administrador está em [petshop_admin](https://github.com/ramosth/petshop_admin).

## Funcionalidades

- 🔐 **Cadastro e login** com token salvo no navegador
- 🛍️ **Listagem e detalhe de produtos**
- ✂️ **Listagem e detalhe de serviços** (banho, tosa etc.)
- Rotas com **React Router** e chamadas HTTP com **Axios**, usando uma instância com o token no cabeçalho

## Como executar

```bash
npm install
npm start
```

A aplicação abre em `http://localhost:3000`.

> A API de back-end era disponibilizada pela disciplina e rodava localmente em `http://localhost:8000`.
